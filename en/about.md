Jenkins is the leading open source automation server. It provides thousands of plugins to support building, deploying and automating any project.

## What is Jenkins?

Jenkins is a self-contained, open source automation server which can be used to automate all sorts of tasks related to building, testing, and delivering or deploying software.

Jenkins can be installed through native system packages, Docker, or even run standalone by any machine with a Java Runtime Environment (JRE) installed.

## A short history

Jenkins is a fork of Hudson.

Hudson was started by Sun Microsystems in 2004, and its first release was published on java.net in 2005.

From 2007 onwards Hudson gradually replaced CruiseControl and other open source build tools as the tool of choice.

In 2008 it won a Duke's Choice Award for Developer Solutions at the JavaOne conference.

In November 2010, Oracle's acquisition of Sun brought the question of Hudson's ownership to the fore.

Despite many agreements between the main project contributors and Oracle, the trademark "Hudson" remained a sticking point.

In December 2010 Oracle claimed the name and the right to apply for the trademark.

As a result, on 11 January 2011 a vote was called to rename the project from "Hudson" to "Jenkins".

On 29 January 2011 the proposal was approved by the community vote, and the Jenkins project was created.

On 1 February 2011 Oracle said it intended to keep developing Hudson and considered Jenkins a fork rather than a rename.

So Jenkins and Hudson continued as two independent projects, each considering the other a fork.

By December 2013 the Jenkins organization on GitHub had 567 project members and around 1,100 public repositories, against 32 project members and 17 public repositories for Hudson.

Today the two have diverged much further, and Jenkins has comprehensively overtaken Hudson.

Jenkins is now the most widely used CI/CD tool on the market.
